# Smart Student Management System

Minimal monorepo containing `backend` and `frontend` for the Smart Student Management System.

Quick start

1. Backend

```bash
cd backend
npm install
# copy .env.example to .env and set values
npm start
```

2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Pushing to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin <your-repo-url>
git push -u origin main
```
